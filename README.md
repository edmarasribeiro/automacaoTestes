# Desafio de Lógica: Sistema de Login

Este projeto exercita a lógica de programação em JavaScript e testes automatizados com Node.js.

## Cenários Testados:
* Login com sucesso.
* Erro de credenciais expiradas.
* Erro de usuário não encontrado.
* Erro de senha incorreta.

## Como rodar os testes:
1. Instale as dependências: `npm install`
2. Execute: `npm test`
